# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Our pledge

We pledge to make participation in this project a welcoming experience for everyone, and to act in ways that build an open and healthy community.

## Scope

This Code of Conduct applies within all project spaces, and also when an individual is representing the project in public spaces.

## Enforcement

Report unacceptable behavior privately by contacting a project maintainer directly. All reports are reviewed and handled confidentially.

For the complete set of guidelines, enforcement responsibilities, and escalation steps, see the linked Contributor Covenant text above.
